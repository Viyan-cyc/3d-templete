# 加载

### 用途

当整页或局部等待数据处理时，明确告知用户当前正在加载。

### 结构

- 动态加载指示、可选加载文字；按钮形态嵌入触发按钮，进度形态嵌入容器。

### 类型

- 一级页面加载、二级局部加载、进度加载、按钮加载。

### 规则

- 整页数据加载使用一级加载；卡片刷新或组件联动使用二级加载。
- 提交、查询等操作使用按钮加载，加载期间该按钮不可重复点击。
- 表格或页签容器可使用进度加载：进度条过渡后显示加载图标，完成后显示完成反馈并消失。
- 加载指示归属于实际等待区域；完成后及时结束，失败时展示明确反馈。

### 交互状态

- 加载中、完成、失败；按实际任务结果切换。

### 视觉参数

- 一级图标 60px，二级图标 30px，进度加载图标 24px，按钮加载图标 14px。
- 一级、二级图标与加载文字间距 8px。

### 状态与视觉细则

| 部位 | 规则 |
| --- | --- |
| 旋转图形 | `color-brand`；未完成进度环轨道使用 `color-fill`，不自行生成深色值 |
| 文字 | `font-size-normal`、`font-line-height-normal`，`color-text-secondary`；图形与文字使用 `space-size-8` |
| 一级／二级定位 | 在所属内容区域内居中，保留导航与区域标题；不根据整个浏览器窗口放置局部加载 |
| 按钮定位 | 加载图标位于按钮图标槽，保留标签和宽度；随按钮内容前景取色，实色按钮不机械使用蓝色图形 |
| 背景与遮罩 | 默认继承容器背景；确需阻止区域交互时使用 `color-bg-mask`，不能透明化整个父容器 |
| 动效 | 复用项目加载动画；原静态资源未定义统一周期，不将自定时长称作 GTS 参数；减少动效模式保留静态标识和文字 |

尺寸指图标本身，不含下方标签；一级60px、二级30px、进度24px、按钮14px不得按导出 SVG 的整体画板高度推导。

- 开始等待时标记所属区域 `aria-busy="true"`；独立状态消息使用 `role="status"`，仅播报必要变化。结束或失败设置为 false，失败展示原因和可用重试入口。
- 加载图标通常为装饰，设置 `aria-hidden="true"`，由文字表达“加载中”。按钮保持可读名称并阻止重复提交；若使用 `aria-disabled` 保留焦点，代码仍须拦截所有触发方式。
- 已知数值进度按 Progress 使用 `aria-valuenow`；未知进度不伪造百分比。请求取消、超时、组件卸载和旧请求返回均需结束或忽略对应等待状态。
- 非阻塞刷新保持旧内容、焦点与容器高度稳定，必要时说明正在刷新；完成后替换内容，不整页闪空。
- 加载后无数据及失败的区分见 [内容状态](<../../设计规范/内容状态.md>)，详细语义见 [键盘与 ARIA](<../../设计规范/键盘与焦点.md>)。

### 不要

- 不要为局部更新遮盖整页并显示页面级加载。
- 不要在任务完成后继续显示加载动画。
- 不要将未知进度伪装为准确完成百分比。
