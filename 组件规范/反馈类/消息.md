# 消息

### 用途

反馈用户主动操作的结果；需要系统级持续提醒时使用通知。

### 结构

- 状态图标、消息文字、可选关闭入口；复杂内容可按场景增加标题、说明或操作。

### 类型

- 全局消息、嵌入式消息。

### 规则

- 全局消息出现在页面顶部居中，距顶部导航 20px，使用投影区分浮层。
- 无关闭图标时，自动消失时间不低于 3s；需要延长时，提示／成功建议 5s，警告／错误建议 10s。
- 有关闭图标时可配置超时消失并允许手动关闭，或仅手动关闭。
- 嵌入式消息仅作用于当前页面或内容区，出现时挤开其他内容，不自动消失，可手动关闭。
- 嵌入式消息不使用阴影；边框为系统高亮默认色、1px。
- 反馈文案明确说明操作结果；错误信息说明可采取的后续动作。

### 交互状态

- 提示、成功、警告、错误；对应 `prompt`、`success`、`warning`、`urgent`。

### 视觉参数

- 左右内间距 16px、上下 8px、图标与文字间距 8px。
- 圆角：`radius-size-normal`；全局消息投影：`shadow3`；嵌入式边框：`border-width-normal` + `color-brand`。
- 错误、告警、提醒、成功、信息、失效背景分别使用 `color-erroe-subtle`、`color-alert-subtle`、`color-warning-subtle`、`color-success-subtle`、`color-info-subtle`、`color-none-subtle`；对应图标分别使用 `color-error`、`color-alert`、`color-warning`、`color-success`、`color-info`、`color-none`；说明文字使用 `color-text-primary`。

### 不要

- 不要让短暂消息承载必须持续查阅的关键信息。
- 不要给嵌入式消息添加浮层阴影或自动消失行为。
- 不要省略错误原因，只留下颜色或图标。
