# 对话框

### 用途

承载与当前任务相关的确认、风险告知、短表单或简单线性流程。

### 结构

- 标题、关闭按钮、内容区、底部操作按钮；可选状态图标、产品名称、二次确认控件。

### 类型

- 基础对话框、高危确认、自定义二次确认、录入确认、表格确认、简单步骤流程。

### 规则

- 根据内容量选择 L1–L5；L1 仅放单列表单，标签与控件优先上下排列；L2–L4 可放多列表单、表格或简单步骤流程。
- 高危操作的确认复选框默认不勾选；未确认前禁用执行按钮，默认焦点置于取消按钮。
- 右上角关闭按钮与取消等效；二次确认可按业务改为输入指定文本等方式。
- 高危说明及长标题／长文本对话框随内容自适应高度，避免纵向滚动隐藏重要信息。
- 小图标形态的图标与标题同行，内容与标题左对齐。
- 步骤流程提供上一步、下一步／完成和取消；下一步／完成置于右侧。
- 携带产品名称时，将其作为次级信息，使用 `color-text-secondary`。

### 交互状态

- 打开后明确当前任务；高危执行按钮区分待确认禁用与确认后可用。
- 执行中沿用按钮加载状态，避免重复触发；关闭或取消退出当前确认。

### 视觉参数

- L1：6 栅格，458px；L2：8 栅格，616px；L3：12 栅格，932px；L4：16 栅格，1248px；L5：24 栅格，全屏。L1–L4 垂直居中。
- 小图标：24×24px。
- 容器内间距和标题／内容／操作区间距：`space-size-20`；按钮间距：`space-size-16`。
- 圆角：`radius-size-medium`；投影：`shadow6`；主题独立边框：`border-width-independent`。

### 不要

- 不要频繁弹出对话框打断非必要操作。
- 不要默认勾选高危确认项，或将默认焦点放在破坏性执行按钮上。
- 不要在二次确认未完成时允许执行。
- 不要将关键风险说明藏在滚动区域中。
- 不要在 L1 对话框中挤入多列表单。
