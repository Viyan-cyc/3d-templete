# 组件索引

- 键盘路径与语义按 [组件交互矩阵](<../设计规范/键盘与焦点.md>) 的对应行执行；空态见 [内容状态](<../设计规范/内容状态.md>)。

## 使用规则

- 按用途从下表读取对应组件；复合组件同时遵循内部按钮、输入框等子组件规则。
- 颜色、字体、圆角、间距、边框和投影的 Token 数值见 [Design System](<../样式Token/设计系统.md>)。
- 组件文档明确指定的部位、状态和尺寸用于该组件，其余参数遵循 Design System。数值为常规配置；已有间距 Token 的紧凑值按 Design System 切换。
- 内间距包含边框宽度；控件宽高不因间距密度变化自动等比缩放。
- 按需采用文档列出的类型和交互状态；禁用状态不可触发操作。
- 每份文档末尾的“不要”用于检查错误用法。

## 组件选择

| 需求 | 组件 |
| --- | --- |
| 收纳操作命令 | 下拉菜单 Dropdown |
| 选择父子层级数据 | 级联选择器 Dropdown |
| 简短文字解释 | 文字提示 Tooltip |
| 说明中包含标题、按钮或结构化内容 | 气泡 Popover |
| 用户操作结果的即时反馈 | 消息 Message |
| 系统级提醒或较完整的结果通知 | 通知 Notification |
| 页面内持续的重要提示 | 警告 Alert |
| 要求确认或处理独立任务 | 对话框 Dialog |
