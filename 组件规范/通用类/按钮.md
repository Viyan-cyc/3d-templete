# 按钮

### 用途

触发命令、提交信息或执行操作，按操作优先级选择按钮类型。

### 结构

- 容器、文字、可选图标；图标按钮可仅保留图标。
- 组合按钮可附带下拉菜单；提交或查询按钮可显示加载指示。

### 类型

- 主要按钮、次要按钮、文本按钮、图标按钮、告警按钮。
- 圆角按钮包含幽灵、主题等形态，按品牌触点和实际场景使用。

### 规则

- 强调程度依次为主要、次要、文本、图标按钮；页面通常只有一个最高优先级的主要按钮，每个按钮组最多一个。
- 中尺寸为默认；大尺寸用于底部全局操作栏等场景；小尺寸用于表格、卡片等复合组件内部。
- 主要按钮通常位于次要按钮右侧；按钮按业务逻辑排序，溢出项收纳至“更多”。
- 单列表单的按钮组位于内容底部并左对齐；弹窗、侧滑面板、多列表单、全局操作栏位于内容底部并右对齐；表格、折叠面板操作区位于内容顶部并右对齐；空状态、结果页的按钮组位于内容底部居中。
- 图标按钮适用于工具栏、侧边导航、表格操作列和树节点；鼠标停留 2s 后显示说明提示。
- 图标操作一般超过 4 个时收纳为按钮组或“更多”菜单。
- 按钮文字超出最大宽度时截断，悬停显示完整提示。

### 交互状态

- 默认、悬停、按下、禁用；提交或查询中显示加载状态并禁止再次点击。
- 可切换图标按钮需区分选中与未选中。

### 视觉参数

- 按钮组间距：`space-size-16`，常规 16px。
- 普通按钮圆角：`radius-size-normal`。
- 主要按钮默认／悬停／按下／禁用填充依次使用 `color-brand`、`color-brand-hover`、`color-brand-active`、`color-brand-disabled`；填充上的文字使用 `color-text-inverse`。文本按钮按相同高亮状态 Token 取色，并核对实际背景下的可读性。
- 次要按钮文字使用 `color-text-primary`，默认／悬停／获焦边框依次使用 `color-border`、`color-border-hover`、`color-border-focus`。带描边的禁用背景使用 `color-fill-disabled-subtle`，文字使用 `color-text-disabled`，边框使用 `color-border-disabled`。
- 危险／错误操作使用 `color-error`；告警、提醒分别使用 `color-alert`、`color-warning`，文字前景按实际对比度使用 `color-text-primary` 或 `color-text-inverse`。功能按钮未定义的悬停／按下／禁用色需补齐确认参数，不从主按钮透明度或旧主题推导。

### 不要

- 不要在同一按钮组放置多个主要按钮。
- 不要将大尺寸按钮普遍用于普通页面操作，或将小尺寸按钮扩散到复合组件以外。
- 不要让图标按钮缺少可理解的文字说明。
- 不要在加载期间允许重复提交。
- 不要通过折行或缩小字号塞入过长按钮文字。
