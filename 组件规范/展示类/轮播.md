# 轮播

### 用途

在有限区域内依次展示同类图片或文字内容。

### 结构

- 内容展示区、当前位置指示器及切换进度。

### 类型

- 圆点式、线段式。

### 规则

- 仅有一条内容时不显示轮播指示器。
- 圆点式通过进度环表达自动切换；进度环 3s 从 0 到 100% 后切换至下一项。
- 线段式当前指示线随进度逐渐加深，区分等待与当前项。
- 指示器可位于图片底部或标题下方，与内容保持稳定的位置关系。
- 指示器按背景对比度使用 `color-icon-inverse` 或 `color-icon-primary`，选中反馈使用本包已定义的状态色；不从图片取色覆盖 UI Token。

### 交互状态

- 等待、当前播放、切换过渡。

### 视觉参数

- 圆点式：等待点直径 4px，当前点直径 6px，进度环直径 14px，指示点间距 20px。
- 线段式指示线宽 80px。

### 不要

- 不要为单条内容显示无效的轮播控件。
- 不要让指示项与当前内容不一致。
- 不要让指示器融入背景而无法辨认。
- 不要把主题无关的信息混在同一轮播中。
