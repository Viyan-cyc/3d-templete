# 列表

### 用途

连续展示结构相同的一组数据，适合按条目浏览信息或执行条目操作。

### 结构

- 等宽条目、主名称；可选前置图标／图片、辅助信息、标签及操作按钮。

### 类型

- 单行文字、单行图标、双行图标、双行标签、双行按钮列表。

### 规则

- 同一列表的条目保持相同的信息结构与对齐方式。
- 仅含名称及一项辅助信息时使用单行列表，辅助信息通常位于右侧。
- 包含多项信息、缩略图或操作时使用双行列表，将补充内容置于名称下方。
- 标签和按钮与所属条目保持明确关联，双行列表可将其放在右侧。
- 优先突出名称，辅助信息保持次级层级。

### 不要

- 不要把信息密度不同的条目随意混排。
- 不要把多项辅助信息和操作挤入单行。
- 不要让右侧操作与相邻条目混淆。
