# 多选框

### 用途

从选项中选择零项、一项或多项，也可表达单项条件是否成立。

### 结构

- 复选标记、选项文字；可选父级全选项、辅助说明或按钮容器。

### 类型

- 基础、父子级、按钮多选、带边框多选、分段多选。

### 规则

- 优先纵向排列，并按字典、使用频率或重要程度排序；分列排列时对齐。
- 选项文字与复选标记共同构成点击热区；悬停时标记反馈，文字颜色保持稳定。
- 单项长标签可换行并保持左对齐；横向组标签建议不超过 20 字，截断时提供完整提示。
- 涉及法律、可靠性或安全性的确认项不得默认勾选。
- 父级控制全部子项：全选子项时父级选中，部分选中时父级半选，无子项选中时父级未选。
- 点击半选父级选中全部子项，点击已全选父级取消全部；不影响其他独立分组。
- 大量选项根据空间使用 Select 或 Transfer。

### 交互状态

- 未选、选中、半选、悬停、禁用。

### 视觉参数

- 基础标记 16px，与文字间距 8px，横向选项间距 16px。
- 基础标记圆角 `radius-size-small`；按钮形态圆角 `radius-size-normal`。

### 不要

- 不要用复选框表达只能选一项的互斥关系。
- 不要把半选状态当作全部选中。
- 不要默认勾选需要用户明确同意的确认项。
- 不要用条件勾选替代需要即时执行的开关。
