# 下拉菜单

### 用途

收纳较多的操作命令，通过触发按钮展开菜单。

### 结构

- 触发按钮、下拉面板、菜单项；可选图标、分割线、分组标题、子菜单箭头及快捷键。

### 类型

- 普通文本、带图标、带分割线、双层、带快捷键、分组下拉菜单。

### 规则

- 点击触发按钮展开菜单；悬停有子级的父项时展开子菜单，点击子菜单项执行操作。
- 多级菜单建议不超过 2 层，重要或高频操作保持在浅层。
- 命令按业务关系分组，并按重要性、使用频率排序；必要时使用分割线或分组标题。
- 多个低频按钮可收纳到“更多操作”入口。
- 有可用快捷键时，在对应菜单项旁显示。

### 交互状态

- 默认、悬停、点击展开、禁用；禁用触发器不可展开。

### 视觉参数

- 菜单面板圆角：`radius-size-medium`；投影：`shadow3`。

### 不要

- 不要将重要、高频命令深藏于多级子菜单。
- 不要无序堆放大量操作。
- 不要把下拉命令菜单当作数据选择器。
- 不要显示实际上不可用的快捷键。
