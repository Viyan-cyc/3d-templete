## 0. 概述与 Token 使用规则

Design Token 将样式名称与实际用途、语义和状态对应。业务组件引用 Token，底层数值集中在主题适配层；组件库的实际变量名可以不同，但颜色必须映射到本文件。

### 0.1 使用规则

- 默认浅色软件界面，直接使用本包 GTS 颜色，不询问用户选择另一套配色。
- 先确定组件部位、用途及状态，再取对应 Token。填充、文字、图标、边框和弱背景分别选色，不能按相近色值互换。
- 保留 Token 名称、大小写和单位，使用 ASCII 连字符；`*` 只表示系列，实际代码需展开成存在的 Token。
- 同一配置下，一个 Token 只对应一组值。常规／紧凑间距分别按表使用，不随视口整体缩放。
- 保留有明确值的颜色和 alpha；不得从相似颜色、固定透明度或反色推导缺失状态。
- 默认、悬停、按下、聚焦、选中、禁用、加载、错误等状态按组件能力实现。重要含义同时使用文字或图标，禁用时实际阻止交互。
- 未定义或待确认的值不可使用；页面确实需要时补齐本包 GTS 定义后再实现，不沿用旧样式填补。

### 0.2 命名与用途

| 类别 | 命名示例 | 使用方式 |
| --- | --- | --- |
| UI 语义色 | `color-brand`、`color-text-primary`、`color-border-focus` | 优先按部位与状态使用 |
| 基础色板 | `brand-50`、`gray-90`、`red-05` | 按用途映射到主题层，不能自动当作组件默认值 |
| 代码与公司辅助色 | `code-keyword`、`company-blue` | 仅用于对应场景；本包检索键不等于库 API |
| 尺寸与排版 | `space-size-16`、`radius-size-normal`、`font-size-normal` | 参数表中的实际名称和值 |
| 投影 | `shadow1`、`shadow2-l` | 几何、方向和 alpha 见投影表，颜色引用 `gray-100Black` |
| 毛玻璃材质 | `--frost-blur-*`、`--frost-surface-*` | 仅用于材质扩展，成套取值；已知参数及待补齐项见第 7 节 |

<a id="color-bindings"></a>

### 0.3 项目接入与颜色核验

- 页面、导航、表格、表单、按钮、下拉面板、弹窗、Tooltip、消息、图表和代码区统一使用本文件；挂载到 body 的浮层也必须获得相同的颜色变量。
- 组件库通过主题接口或集中封装映射到本包 Token；不能直接使用库的默认配色，也不能在局部组件中保留另一套颜色表。
- 不读取旧项目的配色选择字段来改变本包颜色。接入已有页面时，按用途逐项更新全部颜色引用、图表序列与局部覆盖；完成前不声明已完成迁移。
- 非颜色的尺寸、布局、交互与国际化规则按相应章节执行。真实图片内容和业务对象自选颜色不作 UI Token 限制；可控图标、SVG 状态色及图表颜色需纳入检查。
- 图表默认使用 `default` 六色序列；需要无障碍图表时使用完整 `accessible` 序列，这是同一颜色表内的用途配置，不触发配色体系选择。
- 本包没有完整深色 UI 色表；有深色需求时先补齐定义。StarCode 的深色代码区只影响代码容器，不赋予全页面深色支持。

项目 `.gts/color-bindings.json` 记录实际使用的颜色用途。无需配色选择文件，最小格式如下；`theme` 缺省为 `light`，`chartPalette` 缺省为 `default`。

```json
{
  "schema_version": 2,
  "bindings": {
    "button.primary.background": {"token": "color-brand"},
    "page.background": {"token": "color-bg-1"},
    "text.primary": {"token": "color-text-primary"}
  }
}
```

在技能包目录运行 颜色绑定检查（原 Skill：`scripts/check_color_bindings.py`）：

```sh
python3 scripts/check_color_bindings.py --project "/absolute/project"
```

检查限定本文件定义的颜色 Token，拒绝未定义键、待确认值、局部 value 或 fallback。它只检查声明的绑定；还需核对实际代码、库主题及浏览器样式，不能用一份绑定记录替代页面验收。

## 1. GTS 颜色

### 1.1 使用边界

- 软件产品默认高亮色为 `brand-50`（`#0067D1`）；门户官网的高亮建议使用 `gray-90`（`#191919`），不改变全套 GTS 配色。门户高亮完整状态尚未给出，需要时先补齐参数，不套用软件蓝色状态。
- 基础色板的 `gray-0White` 对应 UI 图例中的 `gray-0`；基础色阶按下表统一大小写。
- `focus` 在部分用途说明中标为选中／高亮，按实际组件映射；键盘聚焦仍需单独保持可见，不把选中与聚焦当成同一行为。
- `#RRGGBB / N%` 表示颜色层以 N% 不透明度叠加，实现时转换为 rgba；不能透明化整个组件。
- UI 表提供浅色软件界面的值；代码区的浅／深值仅用于代码区。功能色完整交互态、门户状态及未明确的组件部位参数不能自行推算。

### 2.4 边框与内间距

- 组件内间距标注包含边框宽度。实现时，单侧 `padding + border-width` 等于目标间距。
- 按钮单侧目标内间距为 16px、边框为 1px 时，`padding` 为 15px。
- 输入框外边缘至输入文字的距离为 12px、边框为 1px 时，`padding` 为 11px。
- 标签与输入框之间的 8px 为组件外部间距，不重复计入输入框边框。
- 穿梭框等复合组件按内部各区域的间距配置布局，不将外层间距统一套用到所有内部区域。

### 6.4 不透明度配置与实现

- 各投影另有 80% 不透明度配置，适用主题未明确；仅在主题配置明确指定时使用，不自动套用到深色主题。

- 默认 `shadow1`：`0px 1px 3px 0px rgba(0, 0, 0, 0.1)`；启用 80% 配置时仅将 alpha 改为 `0.8`。
- 业务组件引用投影 Token，不直接复制底层 CSS 值。

## 7. 毛玻璃效果

### 7.1 用途与边界

- 普通业务页面默认实色。仅在需要材质强调的标签、次级按钮、概览卡片和轻量浮层中启用毛玻璃。
- 毛玻璃是材质扩展，不改变 GTS 品牌色、功能色、交互语义、组件结构和尺寸；圆角按[圆角规范](#radius)及具体组件部位取值。
- 默认中性白色磨砂。深色材质须先补齐完整深色 UI 和对应材质参数，不因本节提及深色而启用整页深色主题。
- 实现顺序：确定使用场景 → 选择档位 → 核算面积 → 配置背景与材质 → 保留交互语义 → 验证回退、可读性与性能。

<a id="frost-presets"></a>

### 7.2 材质档位与 Token

| 档位 | 用途 | 选择规则 |
| --- | --- | --- |
| `control` | AI 建议、推荐标签、次级工具按钮 | 同一区域突出 1–3 个，主操作和告警保留原语义 |
| `card` | 指标、智能摘要、概览卡片 | 默认白色磨砂与受控柔和背景；同屏重点卡通常 1–3 张 |
| `overlay` | 菜单、浮动工具条、轻量面板 | 背景复杂时优先提高填充不透明度；长篇内容使用实色 |

同一档位成套使用模糊、填充与阴影参数，不逐组件自由生成数值。面积变大不自动提高模糊强度，先判断背景复杂度与文字可读性。

| Token／检索关键词 | 用途 | 参数状态 |
| --- | --- | --- |
| `--frost-blur-*` | 各档位背景模糊 | 具体名称与数值待补齐 |
| `--frost-surface-*` | 各档位中性填充 | 具体名称、色值与 alpha 待补齐 |
| `--frost-shadow-*` | 各档位阴影 | 具体名称、几何与 alpha 待补齐 |
| `--frost-backdrop-*` | 独立父级柔和渐变背景 | 具体名称、色值及渐变参数待补齐 |
| `--frost-tint-blue`、`--frost-tint-lavender`、`--frost-tint-teal` | 可选薄染色层 | 色值与 alpha 待补齐 |
| `--frost-surface-solid` | 减少透明度及不支持模糊时的不透明表面 | 不透明度 100%；具体色值待补齐 |
| `frost-common`、`frost-light`、`frost-dark` | 公共参数、浅色／深色材质参数组 | 组名为检索关键词，不是可直接引用的 CSS 变量；完整定义待补齐 |
| `frost-decoration` | 色块磨砂装饰参数组 | 已明确参数见[色块装饰](#frost-decoration)，其余几何与渐变参数待补齐 |

`--` 表示 CSS 自定义属性，`*` 仅表示系列。待补齐项不能作为已有可用 Token；实现前须在本设计系统补齐并映射到项目主题层。不得套用旧版 `--glass-*` 数值，或用普通投影的模糊半径代替背景模糊值。参数未齐时保留对应组件的实色样式。

<a id="frost-budget"></a>

### 7.3 应用面积

| 对象 | 建议比例 | 上限／计算口径 |
| --- | --- | --- |
| 常驻毛玻璃总面积 | 主内容视口的 10%–20% | 上限按 25% 控制，不必用满 |
| 淡彩毛玻璃 | 少量使用 | 不超过主内容视口的 8%，计入总面积 |
| 单张重点卡 | 控制面积 | 建议不超过主内容视口的 12% |
| 小标签 | 主内容视口约 1% 以内 | 计入总面积 |
| 工具按钮 | 主内容视口约 2% 以内 | 计入总面积 |

- 按可见毛玻璃表面的并集计算，重叠只算一次；底层渐变不计入模糊面积。临时浮层单独评估。
- 常驻侧栏、表格行、单元格、编辑表单和长篇内容使用实色。
- 一个位置只保留一层背景模糊；毛玻璃卡片内的按钮和标签使用实色或透明填充，不再开启 `backdrop-filter`。
- 面积预算不能代替目标设备上的性能测试。

<a id="frost-background"></a>

### 7.4 背景与染色

- 从底到顶依次为：中性基底 → 边缘缓慢淡出的雾蓝／灰紫渐变 → 中性毛玻璃填充与背景模糊 → 清晰内容。渐变放在独立父级 `.g-frost-backdrop`。
- 默认白色磨砂；深色使用对应中性深灰。淡彩通过薄染色层叠加，一页优先一种染色，不表达成功、告警等功能状态。背景及染色使用前须补齐[材质 Token](#frost-presets)。
- 背景默认静态、大范围淡出，避免鲜艳色块、彩虹分段、持续漂移和发光轮廓。
- 默认不提高背景饱和度；复杂背景可选择 `muted` 降低饱和度，具体参数须统一定义。纯色背景没有可模糊细节，不通过持续提高 blur 补偿。
- 只调整填充层的 alpha，不设置整个组件的 `opacity`；文字、图标和焦点轮廓保持清晰。

<a id="frost-states"></a>

### 7.5 交互状态与回退

| 状态／条件 | 规则 |
| --- | --- |
| Hover／Active | 只调整填充和阴影，使用统一的状态增量 Token；不改变 blur。增量名称及数值须先补齐 |
| Focus／Selected | 焦点沿用清晰轮廓；选中保留品牌边界或标记，不以材质代替状态 |
| Disabled | 使用原禁用语义、阻止交互，并移除模糊 |
| 多层嵌套 | 停止内层背景模糊 |
| 不支持 `backdrop-filter`／减少透明度／产品主动降级 | 使用 `--frost-surface-solid` 完全不透明表面；作用域可设置 `data-transparency="reduced"` |
| 减少动态效果 | 关闭过渡 |
| 高对比模式 | 使用系统颜色，保留内容与重点层级 |

按实际合成背景检查文字可读性，普通文本对比度至少 4.5:1。切换背景、滚动位置及已支持主题后仍须清晰；编译通过不等于视觉验收通过。

<a id="frost-decoration"></a>

### 7.6 品牌色块磨砂装饰

品牌重点卡保留不透明色底与统一白字，通过同色相弱渐变和边角磨砂图形丰富留白。此变体与整块浅色毛玻璃独立，不为添加装饰而将品牌色块改为浅色。

#### 选用规则

- 区域承担总览、主指标或品牌展示，存在大面积单调色底，且边角能避开文字时，可在生成页面时选用。参考尺寸至少 240 × 112 CSS px；尺寸达标不代表必须装饰。
- 同一组默认只选 1 张主卡，同屏通常 1 处、最多 2 处。无色底或内容密集的大卡片保持原样；用户要求简洁或不装饰时关闭。
- 普通卡片、导航、按钮、表格、表单、图表绘图区，以及告警／成功语义色块不使用此装饰。

#### 装饰参数

| 参数 | 规范值／方法 |
| --- | --- |
| 图形数量 | 1–2 个裁切圆形或圆角图形 |
| 默认位置 | 右上和右侧，避开文字 |
| 装饰可见面积 | 宿主面积的 10%–20%，不超过 25%；计入毛玻璃总面积预算 |
| 图形填充 | 白色（`gray-0White`），不透明度由 10% 淡至 2.5% |
| 图形描边 | 白色（`gray-0White`），不透明度 13%；描边宽度待补齐 |
| 图形模糊 | 引用 `control` 档，不单独编造模糊值 |
| 底色 | 品牌蓝同色相弱渐变，不新增紫、粉等色相；具体渐变参数待补齐 |
| 内容色 | 标题、数字和标签统一使用 `color-text-inverse`，通过字号与字重区分层级 |
| 尺寸档位 | 默认 `card`，宽幅概览可用 `panel`；图形尺寸与比例须统一定义 |

- 层次为：同色相弱渐变底 → 边角磨砂图形 → 清晰内容。趋势配合正负号或文字，按合成底色检查白字对比度，避免高光压住文本。
- 宿主保持不透明色底、原有圆角、尺寸与业务布局；不同时启用整块毛玻璃，也不嵌套背景模糊。
- 装饰使用无语义伪元素，不拦截点击、不进入键盘焦点；与组件已有伪元素或定位子项冲突时，使用专用容器。
- 不持续播放动画，不为凑面积比例放大图形。关闭装饰、减少透明度或高对比模式时，保留清晰内容和重点层级。

### 7.7 实现与调用约定

以下为项目样式适配层的调用约定，不是 Sweet UI 或 Element Plus 的原生 API。使用真实组件，通过封装或主题样式承载材质；须实现对应样式并确保属性作用于目标元素，仅添加属性不会自动产生效果。

| 调用标记 | 用法 |
| --- | --- |
| `.g-frost-backdrop` | 承载独立柔和背景 |
| `data-material="frosted"` | 显式启用整块毛玻璃 |
| `data-frost-level="control\|card\|overlay"` | 选择一个材质档位；省略时默认 `card` |
| `data-frost-tint="blue\|lavender\|teal"` | 可选薄染色；不设置时为中性磨砂 |
| `data-frost-tone="muted"` | 降低背景饱和度 |
| `data-surface="brand"` | 品牌蓝底色与白字 |
| `data-decoration="frosted"` | 独立启用色块磨砂装饰，不同时设置 `data-material="frosted"` |
| `data-decoration-size="panel"` | 宽幅装饰比例；省略时为 `card` |
| `data-transparency="reduced"` | 在作用域内关闭透明材质，使用实色回退 |

表内 `\|` 表示可选值，实际属性只填写一个值。需要页面级风格配置时，可用 `visualStyle: "frosted-glass"` 表达材质意图，仍逐区域遵循用途与面积预算，不自动作用于全部组件。

在主题层集中定义参数，通过 `backdrop-filter` 实现背景模糊；为不支持该能力、减少透明度和高对比环境实现对应回退。接入旧 `aurora-glass`、`--glass-*` 或 `.g-glass-*` 时，先明确映射到已补齐的 `frost` 定义，再逐项验证；不直接引入另一套颜色或旧参数。

### 7.8 不要

- 不将整页、常驻侧栏、密集表格或编辑表单统一改为毛玻璃。
- 不把材质、染色或装饰用作成功、告警、禁用、选中等语义的唯一表达。
- 不使用未定义参数、自由生成模糊值，或复制旧材质参数补缺。
- 不模糊文字、降低整个组件透明度、叠加多层背景模糊或遮挡焦点。
- 不为装饰改变组件圆角与布局，不因存在风格配置就自动填满面积预算。
