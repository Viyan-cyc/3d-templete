# 兼容与迁移

## 版本边界

- 包版本：`2.1.0`；Skill 标识：`gts-pc-ui-skill`。
- 本版统一使用当前 GTS 颜色表，不提供配色体系选择。颜色名称及含义以 [Design System](<../样式Token/设计系统.md>) 为准，不能复用旧项目的颜色字典或别名层。
- 保留 GTS 2.2 的布局、间距、圆角、边框尺寸、字体、投影几何和 51 份组件结构／行为规则；组件颜色引用、反馈与示例使用当前 Token。
- 前端组件库接入与记忆沿用现有能力：来源有效时复用，缺少项目依赖时提供 Sweet UI 与 Element Plus 入口并分步引导安装，安装后确认本地路径，真实组件验证后再搭建页面。记忆格式不变。
- Skill 包不绑定单一 Vue／React 版本。旧调用名 `gts-ui-skill` 需由调用方改为当前标识；`radius-size-infinity` 统一使用 `radius-size-infinite`，999px 含义不变。

## 页面迁移

1. 使用本版入口，避免同时加载其他版本的主题样式。
2. 按组件用途和状态重建颜色映射，不按旧 Token 名称或近似 HEX 自动替换。移除旧颜色配置、无效别名、选择分支与局部覆盖，更新图表和代码区。
3. 项目颜色绑定采用 `schema_version: 2`，每条绑定仅记录 `token`；本版不读取配色选择文件。无需更改组件库来源记忆。
4. 当前配色默认浅色 UI；完整深色 UI 参数不足时先补齐，不复用旧深色值。非颜色参数保持既有值。
5. 复查导航、按钮、表格、表单、浮层、反馈和所有适用状态，运行绑定检查与真实页面检查；验证完成前不声明迁移完成。

## 旧版布局配置

原始框架与响应式资料存在不同基准。本包默认使用框架的1440画布与当前 Design System；以下 `legacy-rem-1920` 仅描述已采用旧响应式方案的项目兼容口径，不是当前 Token 的额外一套值。

| 旧版参数 | 1680～1920px | 小于1680px |
| --- | --- | --- |
| rem 基准 | 1rem=16px | 1rem=14px |
| 正文示意 | 14px | 12px |
| 不占栅格的展开左栏 | 320px | 280px |
| 固定居中内容 | 1280px | 1120px |
| 平铺布局图标导航 | 48px | 42px |
| 平铺布局外边距 | 20px | 17.5px |

原资料给出1280／1680／1920断点，但未完整定义该方案在所有范围的行为；尤其不要向极窄屏或超宽屏外推 rem 比例。未采用这套方案的新页面使用默认配置。

从旧方案迁移：记录现有断点、侧栏和字体实测值 → 移除随断点变化的根字号缩放 → 在主题层明确常规／紧凑配置 → 按新栅格重排容器 → 复查1024、1280、1440、1680、1920及缩放、长文案。整块页面一次切换配置，禁止同一容器同时按两套公式计算。

## 升级检查

- 颜色引用只来自当前参数表；I18n Key、变量和格式化行为保留。
- 前端组件库配置与项目真实导入一致；安装与运行检查仍然有效。
- 按项目验证加载、空、失败、禁用、键盘、目标语言、视口与缩放。
- 后续兼容修正递增补丁版本，兼容补充递增次版本；删除 Token 或改变既有值需主版本迁移说明。UI 规范版本单独维护。
