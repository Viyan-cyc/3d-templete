# 键盘与焦点

按 [组件索引](<../组件规范/组件索引.md>) 找到组件，再查本文件对应行。下面是本包补充的实现约定；不改变组件的业务用途、视觉 Token 和“不要”。原生 HTML 语义优先，ARIA 只补缺失信息，不能代替键盘事件和状态逻辑。

## 通用约定

- Tab／Shift+Tab在独立控件间前进／后退。复合控件内部采用单一活动焦点与方向键；不要给每个虚拟项都加 `tabindex="0"`。
- 焦点位置、视觉选中和业务值分开维护。使用 roving tabindex 时，仅活动项为0，其余为-1；使用 `aria-activedescendant` 时 DOM 焦点保留在所属输入／容器，引用实际存在且可见的活动项ID。
- Enter触发按钮与链接，Space触发按钮／复选框；文本编辑器内保留本来的空格、光标、选择与输入法行为。Escape只关闭当前可取消层。
- 可见标签优先通过 `label` 或 `aria-labelledby` 关联；`aria-describedby`关联帮助与错误；无可见标签的图标按钮用具体 `aria-label`。
- `disabled`用于原生禁用；`aria-disabled="true"`不会自动禁用事件，需要拦截鼠标、触摸、键盘和提交。隐藏面板从焦点序列及可访问树移除。
- 表单错误使用 `aria-invalid="true"` 并关联错误描述；必填使用原生 `required` 或适用控件的 `aria-required`。不要在不支持该属性的角色上堆叠 ARIA。

## 导航与基础组件

| 组件 | 键盘路径 | 语义与状态 |
| --- | --- | --- |
| 按钮 Button | Tab定位，Enter／Space执行 | 原生button；切换按钮才用aria-pressed，普通命令不加 |
| 文字链接 Link | Tab定位，Enter跳转 | 有href的a；动作使用button；新窗口行为在名称或说明中提示 |
| 分割线 Divider | 不加入Tab序列 | 有结构意义用hr／separator，装饰线隐藏；不能操作的分割线不加焦点 |
| 滚动条 Scrollbar | 原生滚动优先；内容区需要独立滚动且无可聚焦子项时提供可命名的焦点入口 | 自绘可操作滚动条才用scrollbar、aria-controls、aria-valuemin/max/now及方向；方向键／PageUp/Down／Home/End改变位置 |
| 顶部导航 TopNavigation、侧边栏导航 SideNavigation | Tab访问链接与展开按钮，Enter跳转，Enter／Space展开分组 | nav加名称；当前位置aria-current=page；展开按钮aria-expanded及aria-controls；普通网站导航不强制menu角色 |
| 面包屑 Breadcrumbs、锚点导航 Anchor | Tab到链接，Enter定位 | nav命名；面包屑当前页aria-current=page，当前锚点可用location；固定顶栏下目标标题保持可见 |
| 分页 Pagination | Tab到页码、前后页、跳页输入；Enter执行；输入支持编辑 | nav命名；当前页aria-current=page；到边界禁用相应操作，页码名称可读 |
| 页签 Tabs | Tab进入当前页签，横向Left/Right，纵向Up/Down，Home/End首尾；异步内容Enter／Space激活；Tab离开页签组 | tablist／tab／tabpanel；aria-selected、aria-controls与aria-labelledby；隐藏面板不可聚焦；快速无延迟内容可自动激活 |
| 步骤条 Steps | 只读步骤不逐个聚焦；可返回步骤用Tab、Enter；禁用未来步骤不执行 | 有序列表，当前项aria-current=step；步骤错误由文字说明 |
| 回到顶部 BackTop | Tab定位，Enter／Space返回 | 有可读名称；返回后将焦点放到有意义的页首位置，避免视图和焦点分离 |

页签模型见 [Tabs](https://www.w3.org/WAI/ARIA/apg/patterns/tabs/)；导航中只有实际菜单使用下面的菜单交互。

## 录入与复杂选择

| 组件 | 键盘路径 | 语义与状态 |
| --- | --- | --- |
| 输入框 Input、搜索框 Search、表单 Form | Tab按字段顺序；编辑键正常工作；搜索Enter提交；表单校验失败定位首个错误或可导航的错误摘要 | 原生input／textarea、label；搜索区域可用search；保留错误输入，不在输入法合成期间提交 |
| 数字输入框 InputNumber | Up/Down按步长变化，支持直接输入；Tab访问独立增减按钮 | 原生number或spinbutton；aria-valuemin/max/now，复杂显示可用valuetext；越界反馈不静默改值 |
| 单选框 Radio、评分 Rate | 单选组Tab进入已选项（无选中进入首项），方向键切换，Space选择；只读评分不进入Tab序列 | 原生radio组或radiogroup／radio及aria-checked；评分名称包含分值及总分 |
| 多选框 Checkbox、开关 Switch | Tab进入，Space切换；独立按钮实现的Switch也支持Enter | checkbox或switch及aria-checked；部分选中仅Checkbox使用mixed，Switch只有true／false |
| 选择器 Select | 原生select保留平台交互；自定义单选：打开后Up/Down移动，Enter提交，Escape取消并关闭；可编辑框保留文本编辑 | combobox带aria-expanded、aria-controls和合适aria-haspopup；listbox／option使用aria-selected；可编辑模型焦点留输入，用activedescendant标示选项 |
| 级联选择器 Dropdown | 按钮展开；本包建议各级为有名称的listbox，Up/Down移动，Enter进入子级或提交叶子，Tab访问各级；Escape退一级，根层关闭并回触发器 | 各级listbox／option及aria-selected，名称表达当前路径；若项目采用tree模型则完整遵循Tree规则，不混用menu命令语义 |
| 穿梭框 Transfer | Tab在搜索、源列表、移动按钮、目标列表间切换；列表方向键移动、Space切换选择；移动后焦点保留在操作按钮或合理相邻项 | 两个有名称的listbox，aria-multiselectable=true；option用aria-selected；不要把可交互复选框嵌入option，复选视觉可装饰；播报移动数量 |
| 滑块 Slider | 每个滑块独立Tab入口；Right/Up增，Left/Down减，Home/End边界 | 原生range或slider，aria-valuemin/max/now及可读名称；范围两端分别命名且Tab顺序稳定，不允许越过业务限制 |
| 日期选择器 DatePicker、日历 Calendar | 日历网格仅一个日期为Tab入口；Left/Right逐日，Up/Down逐周，Home/End周首尾，PageUp/Down切月，Shift+PageUp/Down切年；Enter选日期 | 可交互日历用grid／row／gridcell；选中aria-selected，当天aria-current=date，禁用日期语义明确；纯展示日历可保留table，不强制grid |
| 日期时间选择器 DateTimePicker | 日期同上；Tab进入时、分、秒及确认；数值输入按InputNumber，列选项按listbox；确认提交，Escape丢弃未确认修改 | 各时间字段有独立名称／上下界；范围两端分别标识开始与结束，错误关联对应字段 |
| 上传 Upload | Tab到选择文件、删除、取消、重试按钮，Enter／Space执行；拖拽必须有文件选择替代 | 原生文件输入可访问；每个文件操作名称包含文件名；进度与错误关联该文件 |
| 颜色选择器 ColorPicker | Tab到预设色、色值输入、色相／透明度；预设单选按Radio，滑动调整按Slider；Enter确认，Escape取消 | 预设色有名称及色值；输入关联格式说明；不能只提供鼠标可拖动二维色板，需等价键盘输入 |
| 下拉菜单 Dropdown、右键快捷菜单 PopUpMenu | Enter／Space打开菜单并聚焦首项；Up/Down移动，Home/End首尾；Right进入子菜单，Left返回；Enter执行，Escape返回触发点；右键菜单另支持Shift+F10／菜单键 | 触发器aria-haspopup=menu及aria-expanded；menu／menuitem，切换命令用menuitemcheckbox/radio及aria-checked；禁用项不执行；关闭后恢复焦点 |

- Select 的多选模型必须明确：本包建议活动项与选中分离，Space切换非编辑列表选项，Enter提交；可编辑输入的Space保留为输入，使用明确的选中操作。选中标签的删除用独立命名按钮，不让Backspace意外清空输入外的选择。
- 日期弹层若为模态对话框，执行下表模态焦点规则；非模态不加aria-modal，不将所有日期浮层都做成焦点陷阱。打开时定位已有选中日期，否则当天；无效输入先提示修正。
- 可编辑 [Combobox](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/)、多选 [Listbox](https://www.w3.org/WAI/ARIA/apg/patterns/listbox/)、[Slider](https://www.w3.org/WAI/ARIA/apg/patterns/slider/)、[Spinbutton](https://www.w3.org/WAI/ARIA/apg/patterns/spinbutton/)、[日期选择模型](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/examples/datepicker-dialog/) 与 [菜单按钮](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/) 按各自角色实现。

## 展示、浮层与反馈

| 组件 | 键盘路径 | 语义与状态 |
| --- | --- | --- |
| 树形 Tree | Tab到活动节点；Up/Down前后可见节点，Right展开或进首子节点，Left折叠或回父节点，Home/End首尾；Enter执行，Space切换选择 | tree／treeitem／group；仅父节点aria-expanded；选择用aria-selected，勾选型用aria-checked；多选在tree声明aria-multiselectable；异步加载保留活动节点 |
| 表格 Table | 普通数据表保留原生阅读顺序，Tab仅访问排序、筛选、复选与行操作；只有单元格导航／编辑才使用grid，方向键移格，Enter或F2进编辑，Escape退回单元格 | table、caption、th scope；排序列aria-sort；交互grid用row／gridcell并管理单一入口；虚拟行提供正确aria-rowcount/rowindex，不将DOM渲染数量当总数 |
| 列表 List、卡片 Card、时间轴 Timeline、记分卡 ScoreCard | 静态内容不聚焦；内部链接按钮按其自身路径；卡片整块可操作时不能嵌套第二组冲突交互 | 列表用ul/ol，卡片按内容使用section及标题，时间使用time；指标关联名称／单位，趋势以文字表达 |
| 头像 Avatar、徽标 Badge | 纯展示不聚焦；交互头像按按钮或链接 | 有意义头像提供alt；与邻近姓名重复的图片可装饰；徽标数量需完整名称，不只读孤立数字 |
| 折叠面板 Collapse | Tab访问标题按钮，Enter／Space展开收起 | 标题包含button，aria-expanded及aria-controls，内容关联标题；隐藏内容不聚焦 |
| 标签 Tags | 只读标签不聚焦；可选标签Space切换；删除按钮Tab可达，删除后焦点至相邻标签或输入 | 可选标签按切换按钮或Checkbox，明确aria-pressed或aria-checked；删除操作名称包含标签文本 |
| 抽屉 Drawer、对话框 Dialog | 模态打开将焦点移入，Tab／Shift+Tab环绕内部；可取消时Escape关闭并回触发点；高危操作初始焦点优先取消；非模态抽屉允许离开 | dialog+可读名称；真正模态才用aria-modal=true并使背景不可操作；复杂正文不整体塞入aria-describedby |
| 气泡 Popover | 触发器可用键盘，按内容确定焦点位置；Escape关闭；操作内容不能仅悬停显示 | 按内容用非模态dialog、菜单或普通说明，不统一role=tooltip；展开状态和内容关联明确 |
| 文字提示 Tooltip | 触发器focus或hover显示；Escape隐藏；提示本身不聚焦 | role=tooltip，触发器aria-describedby；无交互元素，不能替代必要字段标签 |
| 轮播 Carousel | Tab访问暂停／播放、前后切换；Enter／Space操作；焦点进入及鼠标悬停时暂停自动播放，用户明确启动才恢复 | 有名称的区域；幻灯片说明位置／总数；自动播放期间不连续live播报，隐藏页不可聚焦 |
| 消息 Message、通知 Notification、警告 Alert | 纯提示不抢焦点；关闭／操作按钮Tab可达；含关键操作的提示不在用户操作前过早消失 | 非紧急更新role=status，需立即注意的错误role=alert；避免role与重复live区域造成双重播报 |
| 加载 Loading、进度条 Progress | 不因轮询移动焦点；取消按钮按Button；任务完成焦点保持 | 容器aria-busy，状态role=status；progressbar有名称，已知进度设置valuemin/max/now，未知省略valuenow，不高频播报 |

复杂模式见 [Tree](https://www.w3.org/WAI/ARIA/apg/patterns/treeview/)、[Grid](https://www.w3.org/WAI/ARIA/apg/patterns/grid/)、[折叠面板](https://www.w3.org/WAI/ARIA/apg/patterns/accordion/)、[Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)、[Tooltip](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/) 与 [Carousel](https://www.w3.org/WAI/ARIA/apg/patterns/carousel/)。

## 可执行验收路径

| 任务 | 操作序列 | 通过条件 |
| --- | --- | --- |
| 查询与查看 | Tab到Select → 方向键 → Enter → Tab查询 → Enter → 表格行操作 → 抽屉 → Escape | 值正确提交；结果更新可获知；焦点回到原行操作，数据刷新未丢失定位 |
| 层级与批量选择 | Tree展开父项 → 选择子项 → Transfer选择多项 → 移动按钮 → 目标列表 | 展开／选中状态与ARIA同步；只移动选定项；焦点与播报范围正确 |
| 日期范围提交 | 日期开始值 → 方向键选日 → Tab到结束与时间 → 确认 | 范围合法，未确认值可取消，日期和时间均无需鼠标 |
| 编辑与错误恢复 | 表单填写 → 提交错误 → 错误字段 → 修正 → 提交 → 成功反馈 | 错误说明关联正确，输入保留，无焦点陷阱或重复提交 |
| 上下文操作 | 行触发点Shift+F10 → 子菜单 → Escape逐层退出 | 不依赖右键／悬停；关闭一层只返回上一层；最终恢复触发点 |

在真实目标浏览器与辅助技术上执行后记录结果；此表是验收步骤，不代表这些组件已有实现或已通过读屏测试。

## 不要

- 不要只补role而不实现其键盘模型，或把每种弹层都标成模态。
- 不要通过aria-hidden隐藏仍可聚焦的内容。
- 不要让虚拟化删除当前焦点项，或引用不存在的activedescendant。
- 不要把选择列表当命令菜单，或让排序导致焦点回到页面顶部。
