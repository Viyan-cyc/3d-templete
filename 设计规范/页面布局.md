# 页面布局

## 配置选择

本包默认采用 `framework-1440`：1440px 设计画布、明确的常规／紧凑 Token 配置。已有项目若采用 1920 基准与 rem 缩放，按 [旧版兼容](<兼容与迁移.md#legacy-layout>) 处理；两套参数不可混用。

以下画布、栅格和侧栏数值属于 GTS 框架参数；“窗口适配”表是本包补充的实现建议，不表示每个窗口宽度必须触发同一种布局。

## 画布与内容宽度

| 项目 | 参数／规则 |
| --- | --- |
| 参考画布 | 1440px；另检查 1024、1280、1680、1920px 视口 |
| 基本单位 | 4px |
| Console、作业、数据页面与仪表盘 | 24 列流式栅格；内容随可用宽度增长，不设统一最大宽度 |
| Portal | 12 列固定栅格，标准内容宽度及最大宽度 1280px，整体居中 |
| 固定侧栏 | 位于栅格之外；1024～1920px 范围建议保持所选宽度 |
| 展开侧栏 | 默认 240px；可配置 200～320px |
| 收起侧栏 | 默认 48px；可配置 48～64px |
| 顶部导航 | 按 [顶部导航组件](<../组件规范/导航类/顶部导航.md>) 设置，不由栅格推导高度 |

## 24 列流式栅格

| 参数 | 常规 | 紧凑 | Token |
| --- | --- | --- | --- |
| 槽宽 Gutter | 16px | 8px | `space-size-16` |
| 内容左右边距 Offset | 20px | 12px | `space-size-20` |

设视口宽度为 W、固定侧栏宽度为 S、实际可用内容宽度为 A：

```text
A = W − S − 2 × Offset
Column = (A − 23 × Gutter) ÷ 24
占用 n 列的容器宽度 = n × Column + (n − 1) × Gutter
```

无侧栏时 S=0。若还有固定占位区域，先从 W 中扣除。列宽允许小数，由布局引擎分配，不逐列取整。1440px、240px 侧栏、常规模式下，A=1160px，Column=33px，6 列容器宽278px。

单、双、三列内容区按任务分配列跨度；仪表盘使用流式全宽栅格。具体卡片比例和一行数量由内容决定，不将某张示例图中的比例定为统一规则。

## 12 列 Portal 栅格

标准配置：`1280 = 12 × 92 + 11 × 16`，列宽92px、槽宽16px；剩余空间分配为两侧等宽边距。该固定公式不套用紧凑槽宽。

可用宽度不足1280px及必要外边距时，容器收缩至可用宽度并重排内容；1280px 是标准／最大内容宽度，不是页面最小宽度。禁止通过固定最小宽度使整页被裁切。

## 窗口适配

单位为 CSS px，按浏览器实际视口与内容宽度判断，不读取物理屏幕分辨率来推断可用空间。

| 视口区间 | 实现建议与检查重点 |
| --- | --- |
| 小于1024 | 保持核心任务可用；折叠导航、单列表单、卡片重排；二维表格可局部横向滚动；不据此声明完整移动端支持 |
| 1024～1279 | 重点检查展开侧栏和宽工具栏；空间不足可收起侧栏、收纳低频操作 |
| 1280～1679 | 检查1440参考布局和长文案；Portal 在剩余空间足够时保持1280，否则收缩 |
| 1680～1920 | 检查宽屏的列跨度、侧栏稳定性和内容阅读距离 |
| 大于1920 | 数据页面可流式增长；Portal 保持1280上限；不要自动放大字体或图标 |

密度是显式配置，断点不自动切换字号或密度。采用本建议时，项目记录实际折叠点；用100%、150%、200%缩放复查边界，详见 [适配检查](<响应式与无障碍.md#zoom>)。

## 不要

- 不要把1440参考画布当作浏览器最小宽度，或把1920视为内容统一最大宽度。
- 不要把固定侧栏重复计入24列内容区。
- 不要让旧版 rem 缩放叠加于常规／紧凑 Token 切换。
- 不要把数据表格的局部滚动扩大为整个页面的横向滚动。
