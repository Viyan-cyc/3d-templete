# 国际化


## 文案调用

- 界面文案使用语义 Key：`gts.<component>.<intent>`，不以中文全文、序号或色值作Key。相同文字但业务含义不同可使用独立Key。
- 语言资源与组件分离；标题、按钮、占位、错误、空态和可读名称均纳入资源。项目已有 I18n 框架时沿用，不为本包另建并行翻译系统。
- 完整句子使用命名变量，不拼接可翻译片段；数量复数采用项目支持的 ICU／PluralRules 模型。动态值作为纯文本插入，不能把翻译或用户变量直接赋给innerHTML。
- 开发校验对缺失Key和变量报错；生产可回退至项目默认语言并记录缺失，不直接显示裸Key。生产翻译需目标语言审核。

## Key、组件与 Token 对应

本包提供可复用示例链： 语言资源（原 Skill：`examples/i18n/messages.json`） → 状态绑定（原 Skill：`examples/i18n/bindings.json`） → 调用与渲染（原 Skill：`examples/i18n/status-example.mjs`） → 运行校验（原 Skill：`examples/i18n/check.mjs`）。以下为示例的真实Key和实际Token引用。

| I18n Key | 中文／英文示例 | 语义部位 | Token |
| --- | --- | --- | --- |
| `gts.loading.label` | 加载中／Loading | Loading状态文字；图标另使用强调色 | `color-text-secondary`；`color-brand` |
| `gts.empty.initial` | 尚未添加数据／No data added yet | 首次空态说明 | `color-text-secondary` |
| `gts.empty.noData` | 暂无数据／No data available | 请求成功但无数据 | `color-text-secondary` |
| `gts.empty.noResults` | 未找到符合条件的结果／No matching results | 筛选空态 | `color-text-secondary` |
| `gts.empty.noPermission` | 暂无查看权限／You do not have permission to view this content | 无权限说明 | `color-text-secondary` |
| `gts.empty.notFound` | 内容不存在或已移除／Content not found or removed | 对象不存在 | `color-text-secondary` |
| `gts.empty.partialError` | 此区域暂不可用／This section is temporarily unavailable | 部分失败说明 | `color-error` |
| `gts.error.loadFailed` | 加载失败，请重试／Unable to load. Please retry | 错误说明 | `color-error` |
| `gts.action.retry` | 重试／Retry | 文字操作默认态 | `color-brand` |
| `gts.action.clearFilters` | 清除筛选／Clear filters | 文字操作默认态 | `color-brand` |
| `gts.status.success` | 操作成功／Operation successful | 成功状态文字；成功图标单独取色 | `color-text-primary`；`color-success` |
| `gts.pagination.total` | 共 {count} 条／Total: {count} | 分页总量 | `color-text-secondary` |

这些文字共用 `font-size-normal`／`font-line-height-normal`。绑定由业务语义决定，不根据翻译字符串推断颜色；语言切换不改变Token，主题切换由主题层解析同名Token。表格列出的操作色只代表普通默认态，完整按钮交互仍按组件规范。

运行 `node examples/i18n/check.mjs` 验证中英文Key和占位符一致、文案实际调用、Token存在、语言切换和格式化。示例证明包内调用链存在；不能证明任何既有生产代码已完成国际化。生产验收另需真实页面调用位置、目标语言截图／用例及缺失Key检测结果。

## RTL 镜像矩阵

页面使用与目标语言一致的lang和dir，局部未知方向用户文本可用dir=auto；布局采用逻辑属性处理起点与终点。混排文本用bdi隔离。参见 [HTML方向标记](https://www.w3.org/International/questions/qa-html-dir)。

| 对象 | RTL处理 |
| --- | --- |
| 页面导航、表单标签、工具栏 | 按阅读起点布局；margin/padding-inline-start/end、text-align:start；DOM阅读和Tab顺序一致，不单靠row-reverse反转视觉 |
| 面包屑、分页、返回／前进箭头 | 镜像方向性箭头与布局；“前一页／后一页”仍按逻辑页序，不能反转数值含义 |
| 页签、横向菜单、级联面板 | 根据视觉顺序移动焦点；RTL中键盘Left/Right对应视觉方向；子面板朝有空间一侧展开，方向图标随实际展开方向 |
| 抽屉与浮层 | 按逻辑start/end配置出现方向；物理设备左右具有业务含义时保持，不全局机械镜像 |
| 表格 | 列顺序按阅读方向设计；冻结列用逻辑起点／终点；数值列仍按数值类型对齐，复制与排序使用原始值 |
| 树层级、步骤、时间轴 | 缩进和连接线按阅读方向；时间／步骤语义不倒序；上下层级箭头不镜像 |
| 滑块与进度 | 仅在业务允许时镜像视觉增长方向；取值范围及增加／减少含义不变，键盘与可读值一致 |
| 数字、币种代码、邮箱、URL、设备ID | 不逐字符反转；必要时用bdi及局部dir=ltr隔离，保持复制结果 |
| 图表、趋势图、地理／设备示意 | 不自动翻转坐标、时间顺序或物理方向；由数据语义决定，并复查图例与轴标签 |
| Logo、头像、照片、勾选、关闭、搜索、播放符号 | 非阅读方向图形不镜像；图形内的文字由资源本身处理 |

用实际目标RTL语言检查长标题、分页、菜单、日期面板和焦点顺序；本包的中英示例不等于RTL翻译验收。

## 数值、日期与货币

接口值与展示文本分离；排序、筛选、计算使用原始数值。格式化不能改变原数据、业务精度或单位。

| 类型 | 口径与边界 |
| --- | --- |
| 普通数值 | 指定locale、分组及小数精度；0正常展示，null／undefined是缺失，NaN／Infinity是异常；长ID按字符串保留前导零，不做分组 |
| 百分比 | 比例0.125显示12.5%；接口若传12.5，先按契约转为比例；固定小数位由业务配置，不能隐式重复乘100 |
| 货币 | 明确ISO币种及locale；跨币种表优先显示币种代码以消歧；小数位按币种及业务要求，不能所有币种固定两位；大额精确金额在数据层使用约定的精确类型 |
| 单位 | 明确单位和精度；容量区分GB与GiB、速率区分bit与byte；是否换算由业务决定，不因换语言擅自变更计量口径 |
| 时间点 | 传有Z／偏移的ISO时间或约定的epoch；展示显式指定时区及精度，跨区业务同时说明时区；不能以执行机器默认时区决定业务含义 |
| 纯日期 | 生日、计划日等保留年／月／日语义，不当UTC瞬时时间再转区导致跨日；输入通过明确日期解析器验证，不依赖含糊字符串的Date.parse |
| 范围、时长、相对时间 | 起止采用同一时区／口径；时长不当日期格式化；“刚刚”类文案用国际化能力，需精确值时提供完整时间 |
| 输入与展示 | Intl用于展示，不是本地化解析器；输入说明明确允许格式，解析器处理本地小数符号、日期合法性及夏令时歧义 |

数值和时间显示调用 [Intl规范](https://tc39.es/ecma402/) 的NumberFormat与DateTimeFormat并显式传入配置；资源不足的运行环境由项目补齐locale数据或使用既有兼容库，不静默切换币种／时区。

## 不要

- 不要在组件内散落中文、通过拼接片段构造整句或把Key当生产兜底文案。
- 不要把语言、地区、币种和时区视为同一个配置。
- 不要将颜色Token写进翻译资源值，或凭字面“成功／失败”猜测业务状态。
- 不要把示例测试通过写成真实产品的国际化或无障碍认证。
